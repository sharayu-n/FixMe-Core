
## Authentication
POST   /auth/signup              {name, email, phone, password}
POST   /auth/login               {email/phone, password}
POST   /auth/logout              
GET    /auth/me                  (returns current user profile)
POST   /auth/refresh-token       

## User Profile
GET    /users/me
PUT    /users/me        { name, email, phone }
DELETE /users/me

## AI Generation
POST   /ai/generate-topics       {goal_id} (AI generates topics for goal)
POST   /ai/generate-tasks        {topic_id} (AI generates tasks for topic)
POST   /ai/generate-full-plan    {goal_id} (generates topics + tasks together)

## Week View (Calendar structure)
GET    /weeks                    ?year=&week_number= (list weeks)
GET    /weeks/:week_start        (specific week's data with all plans)
GET    /weeks/current            (current week overview)
POST   /weeks/initialize         {week_start, week_end, year, week_number}

## Streaks & Progress (Dashboard data)
GET    /streaks/me               (current user's streak data)
GET    /dashboard                (overall progress, streaks, stats)
GET    /dashboard/goals          (goal-wise breakdown)
GET    /dashboard/weekly         ?week_start= (weekly summary)
GET    /dashboard/monthly        ?year=&month= (monthly summary)

## Analytics (Future data insights)
GET    /analytics/time-spent     ?start_date=&end_date=&goal_id=
GET    /analytics/completion-rate ?start_date=&end_date=
GET    /analytics/productivity   ?period=week|month|year
